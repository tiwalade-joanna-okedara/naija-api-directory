# Contributing

Thanks for helping keep this list useful.

1. Edit `services.json`. Add your service to the right category with `name`, `url`, `what`, `status` (`active`, `acquired` or `closed`), `note` and `tags`.
2. Keep descriptions factual and short. Link to the provider's own site or docs.
3. If a service has shut down or been acquired, change its status and add a source in your pull request description.
4. No affiliate links, no adverts, no personal attacks.
5. Regenerate the README tables if you can (or just say so in the PR and the maintainer will).
